# Security Policy

## Supported versions

This project is in beta. Security fixes are made on the latest release only.

| Version | Supported |
|---|---|
| Latest 0.1.x beta | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/mirkomikulic/fdb-record-layer-python/security/advisories/new)
(Security tab → "Report a vulnerability").

Include what you found, how to reproduce it, and the affected versions. You
should get a first response within 7 days. We'll keep you updated while we work
on a fix and credit you in the advisory unless you prefer otherwise.

Vulnerabilities in FoundationDB itself should be reported to the
[FoundationDB project](https://github.com/apple/foundationdb/security).
